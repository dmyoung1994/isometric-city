# IsoGolf Sprite Prompts

Use this list to generate a cohesive isometric sprite pack for IsoGolf.

## Global Style
- Isometric view, ~2:1 tile ratio
- Soft shadows, saturated but natural colors
- Clean silhouettes with minimal noise
- Transparent background (or red key background if exporting to a sheet)
- Consistent light source (top-left)
- No text or logos
- No perspective drift across assets

## Sheet Specs
- Suggested sheet grid: 6 columns x 5 rows
- Cell size: 128x128 px
- Sprite scale consistent across the sheet
- Keep each asset centered in its cell, with modest padding
